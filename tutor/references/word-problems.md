# Tutoring Word Problems

Word problems fail learners in predictable places. Diagnose *where* the learner is stuck before helping, because the fix is different for each.

| Where they're stuck | Signs | What to do |
|---|---|---|
| Reading / comprehension | Can't restate the problem; misreads the situation | Slow down, go sentence by sentence |
| Identifying the goal | Calculates something, but not what was asked | Ask "what exactly are we finding?" and "what units will the answer be in?" |
| Sorting information | Uses every number given, including irrelevant ones; misses implied info | Ask them to sort given info into "need" and "don't need" |
| Translating to math | Understands the story but can't set up the equation or operation | Map key phrases to operations; draw a picture or table |
| Computation | Setup is right, arithmetic is wrong | Ask them to recheck the specific step |
| Checking | Gets an answer that makes no sense in context | Ask "does this make sense in the real world?" |

## Step-by-step approach

### Step 1: Restate in their own words
"Before any math, tell me in your own words what's happening in this problem."
If they just repeat the problem verbatim, ask them to explain it as if to a younger student, or to describe it as a short story.

### Step 2: Identify what's being asked
"What is the question asking you to find?"
Follow-ups:
- "What will the answer look like: a number of people? A time? A price?"
- "What units should the answer be in?"
- "Is it asking for a total, a difference, a rate, or something else?"

Watch for problems with multiple parts or a hidden final step (e.g., the question asks for change from $20, not the total cost). A common error is solving for an intermediate value and stopping.

### Step 3: Sort the information
"What information does the problem give you?" Then:
- "Which of these do you actually need?"
- "Is there anything here that's just extra detail?"
- "Is there information you need that isn't stated directly?" (e.g., there are 60 minutes in an hour, a week has 7 days)

### Step 4: Plan before computing
"How could you set this up?" Suggest representations if they're stuck:
- Draw a picture or diagram
- Make a table
- Write an equation with a named unknown ("Let n be…")
- Try a simpler version with smaller numbers

Key phrase prompts (ask, don't tell): "What operation does 'how many more than' suggest to you? Why?"

### Step 5: Solve
Let them compute. Ask for work if they skip steps.

### Step 6: Check against the story
"Does your answer make sense in the context of the problem?"
- "Can you have a fraction of a person / bus / ticket?"
- "Is it reasonable that a car traveled 4,000 miles in an hour?"
- "Plug your answer back in. Does everything in the story work out?"

## Assessing comprehension separately

To check whether the learner can make out what a word problem asks, you can occasionally give a word problem and ask *only* "What is this asking you to find, and what do you need to know to find it?" without asking them to solve it. This isolates the reading skill. Do this especially if earlier errors suggested they misread problems.

## Common misreadings to watch for

- Confusing "more than" / "less than" order ("5 less than x" is x − 5, not 5 − x)
- Treating "per" carelessly in rate problems
- Answering with the wrong unit (minutes vs. hours)
- Stopping at an intermediate result
- Using all numbers given because "they must be there for a reason"
- Missing a negation ("how many did NOT attend")
